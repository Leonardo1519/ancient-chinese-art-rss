# Privacy Policy - 设计视界 · 思政融新

**Last Updated**: January 2026

## Data Collection

This extension **does not collect, transmit, or share any user data**.

## Data Storage

- All data (articles, settings, favorites) is stored **locally** in your browser using the browser's storage API
- No data is sent to external servers
- No analytics or tracking is performed

## Permissions Explanation

The extension requests the following permissions:

### storage
- **Purpose**: Store RSS feeds, articles, user settings, and favorites locally
- **Data**: Stored only in your browser, never transmitted

### alarms
- **Purpose**: Schedule automatic RSS feed updates
- **Data**: No data collected

### notifications
- **Purpose**: Notify you of new articles (if enabled)
- **Data**: No data collected

### Host Permissions (various websites)
- **Purpose**: Fetch RSS feeds from design and cultural websites
- **Data**: Only RSS feed content is fetched and stored locally

## Third-Party Services

This extension fetches RSS feeds from various public websites. The extension itself does not track or collect information about your usage of these services.
